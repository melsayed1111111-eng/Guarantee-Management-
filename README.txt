   تطبيق إدارة ضمانات الأجهزة + Firebase
   مع نظام مستخدمين وصلاحيات
═══════════════════════════════════════════════

محتويات الملف:
  • index.html       — التطبيق الرئيسي (تسجيل دخول + صلاحيات)
  • manifest.json    — ملف تعريف التطبيق (للتثبيت كـ PWA)
  • sw.js            — خدمة العمل بدون إنترنت
  • icons/           — أيقونات التطبيق

───────────────────────────────────────────────
🔑 بيانات الدخول الافتراضية
───────────────────────────────────────────────

   اسم المستخدم:  admin
   كلمة المرور:   admin123

   ⚠️ أول مرة تسجّل دخول بحساب admin، التطبيق
   ينشئ الحساب تلقائياً في Firebase Authentication
   (لا حاجة لإنشائه يدوياً).

───────────────────────────────────────────────
⚠️  مهم جداً قبل التشغيل: إعداد Firebase
───────────────────────────────────────────────

التطبيق متصل بمشروعك:  guarantee-management
يجب تفعيل خدمتين فقط من لوحة Firebase:

🔹 الخطوة 1) تفعيل Firestore Database
   • افتح: https://console.firebase.google.com
   • اختر مشروع "guarantee-management"
   • من القائمة: Build ← Firestore Database
   • اضغط "Create database"
   • اختر Production / Test mode (Test أسهل للبداية)
   • اختر أقرب موقع جغرافي (مثلاً eur3)

🔹 الخطوة 2) تفعيل Email/Password Authentication
   ⚡ هذه الخطوة الأهم — التطبيق لن يعمل بدونها
   • من القائمة: Build ← Authentication
   • اضغط "Get started"
   • تبويب "Sign-in method"
   • اضغط على "Email/Password"
   • فعّله (Enable) ← اضغط Save

🔹 الخطوة 3) قواعد أمان Firestore
   • Firestore Database ← Rules
   • انسخ والصق:
     ─────────────────────────────────
     rules_version = '2';
     service cloud.firestore {
       match /databases/{database}/documents {

         // الأجهزة: قراءة وكتابة لأي مستخدم مسجل دخول
         // (الصلاحيات الدقيقة محمية من واجهة التطبيق)
         match /devices/{deviceId} {
           allow read, write: if request.auth != null;
         }

         // المستخدمون: كل واحد يقرأ بياناته،
         // والإدارة الكاملة لمن دوره admin
         match /users/{userId} {
           allow read: if request.auth != null;
           allow write: if request.auth != null
             && get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 'admin';
         }
       }
     }
     ─────────────────────────────────

🔹 الخطوة 4) إضافة الدومين في Authorized Domains
   • Authentication ← Settings ← Authorized domains
   • أضف الدومين الذي ستستضيف عليه التطبيق
   • localhost موجود تلقائياً (للاختبار المحلي)

───────────────────────────────────────────────
👥 نظام الصلاحيات
───────────────────────────────────────────────

التطبيق يدعم 3 مستويات من الصلاحيات:

┌─────────────┬──────────┬────────┬──────┬──────────────┐
│  الدور      │  إضافة   │ تعديل  │ حذف  │ إدارة المستخدمين │
├─────────────┼──────────┼────────┼──────┼──────────────┤
│ admin       │    ✓     │   ✓    │  ✓   │      ✓       │
│ editor      │    ✓     │   ✓    │  ✕   │      ✕       │
│ viewer      │    ✕     │   ✕    │  ✕   │      ✕       │
└─────────────┴──────────┴────────┴──────┴──────────────┘

─ كيف تضيف مستخدم جديد ─
1. ادخل بحساب admin
2. اضغط على تبويب "المستخدمون" بالأعلى
3. اضغط "إضافة مستخدم"
4. اكتب اسم المستخدم (حروف لاتينية وأرقام)،
   كلمة المرور، واختر الصلاحية
5. اضغط حفظ

   ✨ المستخدم يُسجَّل تلقائياً في Firebase Authentication
   بدون الحاجة لفتح لوحة Firebase.

   يمكنك تعديل صلاحية أي مستخدم لاحقاً، أو حذفه من النظام
   (الحذف من Firebase Auth يتم يدوياً من لوحة Firebase).

───────────────────────────────────────────────
طريقة التشغيل
───────────────────────────────────────────────

▸ التطبيق يحتاج سيرفر بسيط (لأن Firebase + Service Worker
  لا يعملان من بروتوكول file://).

▸ أسهل طريقة محلياً:

  • إذا عندك Node.js:
      npx serve warranty-app
      ثم افتح: http://localhost:3000

  • إذا عندك Python:
      cd warranty-app
      python -m http.server 8000
      ثم افتح: http://localhost:8000

▸ للنشر على الإنترنت (مجاناً):
  • Netlify Drop (الأسرع):
      اسحب وأفلت مجلد warranty-app على:
      https://app.netlify.com/drop

  • Vercel:        https://vercel.com
  • Firebase Hosting (الأنسب — من نفس مشروعك):
        npm i -g firebase-tools
        firebase login
        firebase init hosting
        firebase deploy

───────────────────────────────────────────────
كيفية تثبيت التطبيق على الجوال (PWA)
───────────────────────────────────────────────

▸ على iPhone / iPad (Safari):
  1. افتح رابط التطبيق في Safari
  2. اضغط زر المشاركة (المربع مع السهم)
  3. اختر «إضافة إلى الشاشة الرئيسية»

▸ على Android (Chrome):
  1. افتح رابط التطبيق في Chrome
  2. ستظهر رسالة "تثبيت التطبيق" تلقائياً
  3. أو من القائمة (⋮) اختر «تثبيت التطبيق»

▸ على الكمبيوتر (Chrome / Edge):
  ستجد أيقونة تثبيت في شريط العنوان
  أو اضغط زر «تثبيت التطبيق» من داخل التطبيق نفسه.

✓ متجاوب مع جميع الأجهزة
✓ قابل للتثبيت كتطبيق PWA على الموبايل والكمبيوتر
✓ تصدير واستيراد البيانات بصيغة JSON
✓ سجل من قام بإضافة/تعديل كل جهاز

البنية في Firestore
───────────────────────────────────────────────

  Collection: devices
    • name, type, company, purchaseDate, warrantyEnd
    • employee, createdByUsername, createdAt, updatedAt

  Collection: users   (doc id = Firebase Auth UID)
    • username, email, role (admin|editor|viewer)
    • createdAt, createdByUsername
