   تطبيق إدارة ضمانات الأجهزة + Firebase
═══════════════════════════════════════════════

محتويات الملف:
  • index.html       — الصفحة الرئيسية (متصل بـ Firebase)
  • manifest.json    — ملف تعريف التطبيق (للتثبيت)
  • sw.js            — خدمة العمل بدون إنترنت
  • icons/           — أيقونات التطبيق

───────────────────────────────────────────────
⚠️  مهم جداً قبل التشغيل: إعداد Firebase
───────────────────────────────────────────────

التطبيق متصل بمشروعك على Firebase:
   guarantee-management

لكي يعمل الحفظ والقراءة، يجب أولاً:

1) تفعيل Firestore Database
   • افتح: https://console.firebase.google.com
   • اختر مشروع "guarantee-management"
   • من القائمة الجانبية: Build ← Firestore Database
   • اضغط "Create database"
   • اختر Production mode أو Test mode
     (Test mode أسهل للبداية لكنه يفتح القراءة لأي شخص لمدة 30 يوم)
   • اختر أقرب موقع جغرافي (مثلاً eur3 أو us-central1)

2) ضبط قواعد الأمان (Rules)
   • داخل Firestore Database → Rules
   • للاستخدام الشخصي السريع (مفتوح):
     ─────────────────────────────────
     rules_version = '2';
     service cloud.firestore {
       match /databases/{database}/documents {
         match /devices/{deviceId} {
           allow read, write: if true;
         }
       }
     }
     ─────────────────────────────────

   ⚠️ ملاحظة: القاعدة أعلاه تسمح لأي شخص يعرف رابط
   مشروعك بالقراءة والكتابة. للاستخدام الجاد يفضّل
   إضافة Authentication لاحقاً.

3) إضافة الدومين في Authorized Domains
   • Firebase Console → Authentication → Settings → Authorized domains
   • أضف الدومين الذي ستستضيف عليه التطبيق
     (localhost موجود تلقائياً)
   • أمثلة: yourapp.netlify.app, yourapp.vercel.app

───────────────────────────────────────────────
طريقة التشغيل
───────────────────────────────────────────────

▸ التطبيق يحتاج سيرفر بسيط (لأن Firebase + Service Worker
  لا يعملان من بروتوكول file://).

▸ أسهل طريقة محلياً:

  • إذا عندك Node.js:
      npx serve warranty-app
      ثم افتح: http://localhost:3000

  • إذا عندك Python:
      cd warranty-app
      python -m http.server 8000
      ثم افتح: http://localhost:8000

▸ للنشر على الإنترنت (مجاناً):
  • Netlify Drop (الأسرع):
      اسحب وأفلت مجلد warranty-app على:
      https://app.netlify.com/drop

  • Vercel:        https://vercel.com
  • Firebase Hosting (الأنسب):
      من نفس مشروعك:
        npm i -g firebase-tools
        firebase login
        firebase init hosting
        firebase deploy

───────────────────────────────────────────────
كيفية تثبيت التطبيق على الجوال
───────────────────────────────────────────────

▸ على iPhone / iPad (Safari):
  1. افتح رابط التطبيق في Safari
  2. اضغط زر المشاركة (المربع مع السهم)
  3. اختر «إضافة إلى الشاشة الرئيسية»

▸ على Android (Chrome):
  1. افتح رابط التطبيق في Chrome
  2. ستظهر لك رسالة "تثبيت التطبيق" تلقائياً
  3. أو من القائمة (⋮) اختر «تثبيت التطبيق»

▸ على الكمبيوتر (Chrome / Edge):
  ستجد أيقونة تثبيت في شريط العنوان
  أو اضغط زر «تثبيت التطبيق» من داخل التطبيق نفسه.

───────────────────────────────────────────────
المميزات
───────────────────────────────────────────────

✓ حفظ سحابي حقيقي عبر Firebase Firestore
✓ مزامنة فورية بين كل الأجهزة (real-time)
✓ يعمل بدون إنترنت — البيانات تُحفظ محلياً
   ثم تُرفع تلقائياً عند رجوع الاتصال
✓ تصميم زجاجي شفاف احترافي (Glassmorphism)
✓ يدعم اللغة العربية بالكامل (RTL)
✓ متجاوب مع جميع الأجهزة (موبايل / تابلت / كمبيوتر)
✓ قابل للتثبيت كتطبيق على الموبايل والكمبيوتر
✓ تصدير واستيراد البيانات بصيغة JSON
✓ مؤشر حالة الاتصال بالسحابة
✓ بحث وفلترة حسب حالة الضمان
✓ إحصائيات فورية (ساري / قارب / منتهي)

───────────────────────────────────────────────
حقول البيانات المحفوظة في Firestore
───────────────────────────────────────────────

  Collection: devices
  Document fields:
    • name          — اسم الجهاز / الديفايس
    • type          — نوع الجهاز
    • company       — اسم الشركة
    • purchaseDate  — تاريخ الشراء
    • warrantyEnd   — تاريخ انتهاء الضمان
    • employee      — اسم موظف المشتريات
    • createdAt     — وقت الإنشاء (تلقائي)
    • updatedAt     — وقت آخر تعديل (تلقائي)
