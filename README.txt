   تطبيق إدارة ضمانات الأجهزة

محتويات الملف:
  • index.html       — الصفحة الرئيسية للتطبيق
  • manifest.json    — ملف تعريف التطبيق (للتثبيت)
  • sw.js            — للعمل بدون إنترنت (offline)
  • icons/           — أيقونات التطبيق

───────────────────────────────────────────────
طريقة التشغيل
───────────────────────────────────────────────

▸ الطريقة الأولى (الأبسط - فتح مباشر):
  افتح ملف index.html بأي متصفح حديث
  (Chrome / Edge / Safari / Firefox / Brave).

▸ الطريقة الثانية (مع التثبيت كتطبيق):
  لتثبيت التطبيق على جوالك أو جهازك،
  يجب أن يُشغَّل عبر سيرفر بسيط أو يُرفع
  على استضافة (لأن المتصفحات تشترط ذلك للـ PWA).

  أسهل طريقة محلياً (إن كان عندك Python):
    1. افتح موجه الأوامر داخل مجلد التطبيق
    2. نفّذ:    python -m http.server 8000
    3. افتح:    http://localhost:8000

  أو ارفع المجلد على أي استضافة مجانية:
    • Netlify Drop  →  https://app.netlify.com/drop
    • Vercel         →  https://vercel.com
    • GitHub Pages   →  https://pages.github.com

───────────────────────────────────────────────
كيفية تثبيت التطبيق على الجوال
───────────────────────────────────────────────

▸ على iPhone / iPad (Safari):
  1. افتح رابط التطبيق في Safari
  2. اضغط زر المشاركة (المربع مع السهم)
  3. اختر «إضافة إلى الشاشة الرئيسية»

▸ على Android (Chrome):
  1. افتح رابط التطبيق في Chrome
  2. ستظهر لك رسالة "تثبيت التطبيق" تلقائياً
  3. أو من القائمة (⋮) اختر «تثبيت التطبيق»

▸ على الكمبيوتر (Chrome / Edge):
  ستجد أيقونة تثبيت في شريط العنوان
  أو اضغط زر «تثبيت التطبيق» من داخل التطبيق نفسه.
